# Sudar Muthu A — Developer Portfolio

A responsive, dark-premium personal portfolio for **Sudar Muthu A**, built with HTML, CSS and vanilla JavaScript.

## Features

- Dark premium visual theme with blue/cyan accents
- Responsive desktop, tablet and mobile layouts
- Animated hero headline
- Scroll reveal animations
- Mobile navigation menu
- Project category filters
- Reading progress indicator
- Back-to-top control
- Resume download link
- Reduced-motion accessibility support

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans and Space Grotesk)

## Run locally

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Check all sections, responsive layouts, resume download and contact links.

No build step or package installation is required.

## Before publishing

Please review these details:

1. Confirm the phone number, email address, education details and project descriptions.
2. Add your actual GitHub and LinkedIn profile URLs. The supplied resume showed profile labels but did not contain their URLs.
3. Add verified repository links to the project cards if you want visitors to open your source code.
4. The resume PDF is included in `assets/resume/`.
5. If you want a profile photograph, add your chosen image and update the hero section intentionally.

## Deploy

This is a static website and can be deployed using GitHub Pages, Netlify or Vercel.

### GitHub Pages (quick outline)

1. Create a GitHub repository, for example `sudar-muthu-portfolio`.
2. Push the project files to the repository.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the published URL shown in the Pages section.
